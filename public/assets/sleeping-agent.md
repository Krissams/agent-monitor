# Sleeping agent artwork

`public/assets/sleeping-agent.png` was created with OpenAI image generation for Agent Monitor. It follows the project's cream robot, dark hoodie, headset, and lavender studio visual direction. The local prototype's supplied dashboard reference image is not redistributed.

The interface uses this image for completed agents whose result is read. Working and attention states use project-authored SVG characters. Floating Zzz letters are CSS animation layered over the sleeping image.

## Generation brief

Create a single landscape 3:2 sleeping mascot illustration: a friendly, cream-colored rounded robot with a dark hoodie, orange headset, small antenna, and rosy cheeks. Its eyes are closed, head resting on folded arms over a closed laptop on a desk. Use a cozy lavender studio, warm desk light, and soft toy-like materials. Keep the face recognizable in small thumbnail crops. No dashboard UI, text, watermarks, or Z letters; the interface adds those separately.

See `docs/ASSETS.md` for project licensing and screenshot guidance.
